# WritoShop Test

Standalone test repository for the redesigned WritoShop frontend.

## Stack
- React 19
- TypeScript
- Vite
- Tailwind CSS 4
- React Router
- Lucide icons

## Vercel
Import this repository into Vercel. The included `vercel.json` uses `npm run build` and outputs `dist`.

This test repo is separate from the production `writoshop` repository.
